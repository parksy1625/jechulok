점검 준비

    HEIC 버튼은 외부 CDN에서 디코더 코드를 불러옵니다. 실제 아이폰 사진 지원 여부는 별도 검증이 필요해요.

    내 기기 작업 기록

    기록은 기본적으로 꺼져 있어요. 다운로드 시작은 실제 저장 완료와 다를 수 있습니다.

    파일 이름·내용·오류 원문을 기록하지 않으며 서버로 전송하지 않습니다. 오류 분류는 최근 35건까지 저장합니다.

    문제 해결 안내

    HEIC·AVIF 사진을 열 수 없어요

    최신 브라우저로 업데이트하고 HEIC 디코더의 인터넷 연결을 확인하세요.

    PDF 변환이 안 돼요

    암호화·전자서명·양식 지원 여부와 PDF 라이브러리 연결을 확인하세요.
