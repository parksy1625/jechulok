사진·PDF 파일

제출OK의 이미지 규격 맞춤, 일괄 변환, ZIP 다운로드, 사진으로 PDF 만들기 작업은 사용자의 브라우저에서 처리합니다. 파일 내용, 사진, 문서 원문 또는 파일 이름을 제출OK 변환 서버에 업로드하지 않습니다.

호스팅 접속 기록

Vercel 등의 호스팅 서비스는 접속 IP 주소, 요청한 페이지, 접속 시각과 같은 일반적인 서버 접속 정보를 보안·운영 목적으로 처리할 수 있습니다.

방문자 분석

Vercel Web Analytics가 Vercel 대시보드에서 활성화된 경우, 쿠키를 사용하지 않는 익명 방문·페이지 조회 통계가 처리될 수 있습니다. 사진 파일이나 제출 규격 입력값을 통계로 전송하지 않습니다. 분석 기능은 별도 활성화 전에는 측정되지 않습니다.

설정은 이 브라우저의 로컬 저장소에 기록되고 다음 페이지부터 적용됩니다. 브라우저의 Do Not Track 설정도 존중합니다.

내가 사용한 도구

홈 화면의 다운로드 횟수는 해당 브라우저에만 저장하며, 사이트 전체 사용자의 통계가 아닙니다. 브라우저 저장 데이터를 삭제하면 이 내역도 삭제됩니다.

저장 기간과 서비스 운영

업로드한 파일과 변환 결과를 별도 서버 데이터베이스에 저장하지 않습니다. Vercel이 수집한 접속·방문 통계의 보관 및 처리에는 Vercel 정책이 적용됩니다. 서비스 제공을 위해 추가되는 기능에 따라 안내를 갱신합니다.

새 PDF 도구 및 외부 라이브러리

PDF·HEIC 변환 라이브러리는 사이트 내부의 검증된 파일을 우선 불러옵니다. 장애 시 외부 CDN을 대체 경로로 사용할 수 있습니다. 공급자는 코드 다운로드 시 IP 등 접속 정보를 처리할 수 있으나 PDF 파일 원문은 브라우저를 떠나지 않습니다. 이미지 기반 압축은 텍스트 검색 및 일부 PDF 기능을 잃을 수 있습니다.

HEIC·AVIF 변환

HEIC 변환 시 외부 CDN에서 디코더 코드를 내려받을 수 있습니다. 원본 사진은 브라우저에서 처리하며 파일 내용은 제출OK 서버나 디코더 CDN에 업로드하지 않습니다. JPG로 변환하면서 EXIF 등 촬영 메타데이터와 다중 프레임이 유지되지 않을 수 있습니다.
